Optional browser setup

Load the extension for full access to your current browser tab. Skip this step if you do not use browser actions.

  1. Open chrome://extensions in Chrome or edge://extensions in Edge.
  2. Turn on Developer mode and choose Load unpacked.
  3. Select %LOCALAPPDATA%\Programs\Cursivis\desktop\browser-extension-chromium.
  4. Refresh the tab you want to use. If the extension was already loaded, click Reload first.

Advanced fallback

If Setup cannot download the runtime, download the matching ZIP, leave it next to the 1.5.4 Setup EXE without extracting it, and run Setup again. Setup verifies the ZIP before installing.
