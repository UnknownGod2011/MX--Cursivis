Best experience for new users

Start with your own Gemini API key

Cursivis works best when you add your own Gemini API key. This is the recommended setup for fast text and image responses and for Cursivis Live Mode. Local LLM mode remains available later from Settings for users who prefer on-device processing.

Automatic on your PC

What happens after you click download

Setup handles the runtime connection for you. You do not need Visual Studio, VS Code, Node.js, PowerShell commands, or manual port setup.

Installs Companion

Adds the Companion app and local runtime under your Windows user account.

Connects Logitech actions

Creates the local profile used by the Marketplace plugin, Actions Ring, Creative Console, and Go shortcut.

Adds Live Mode

Enables an optional permission-aware voice session inside the same Cursivis Companion and unified runtime.

Starts quietly with Windows

Registers Companion and the hotkey host so your triggers are ready after sign-in.

Preserves your choices

Updates keep your API keys, selected backend, shortcuts, and local preferences.

Includes browser support

Advanced control of your current browser tab uses included extension files. Chrome-family browsers still ask you to approve the extension once for security.
