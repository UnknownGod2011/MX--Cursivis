Windows may ask for permission before running setup. That is expected. The setup installs only the local Cursivis runtime and keeps your API keys on your computer.

1
Install the Logitech plugin

Use Logitech Marketplace / Logi Options+ to add Cursivis.

2
Download Companion Setup

Open the downloaded file. It handles the runtime setup.

3
Choose AI backend

Add your API keys or choose a Local LLM from Settings.

What Companion Setup Does

Connects the plugin

Writes the local runtime profile used by the Logitech plugin to find Cursivis Companion on your PC.

Installs the runtime

Adds Companion, backend, browser action support, and the gesture hotkey host to your local app data folder.

Starts with Windows

Registers the background pieces so Logitech actions work after restart without opening developer tools.

Keeps setup simple

Downloads portable Node only if needed. Local LLM models download later only when you choose that option.

See Cursivis In Flow

Assign Cursivis actions in Logi Options+, select real on-screen content, and trigger useful AI responses without leaving your work.
